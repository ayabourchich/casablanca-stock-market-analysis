# Casablanca Stock Market Analysis

## About the Project

This is a personal academic project where I worked on analyzing data from the Casablanca Stock Exchange.

The goal was to use Python and Machine Learning to study stock market data, understand market trends, and explore predictions. I also used Power BI to create a dashboard to visualize the results.

## What I Did

- Cleaned and prepared the stock market data using Python.
- Explored and analyzed the available data.
- Developed a Machine Learning model.
- Prepared the results for Power BI.
- Created a dashboard to visualize the data.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Power BI

## How to Run

First, install the required libraries:

```bash
pip install -r requirements.txt
```

Then run the Python files in this order:

```bash
python 1_nettoyage.py
python 2_ml_model.py
python 3_export_powerbi.py
```
